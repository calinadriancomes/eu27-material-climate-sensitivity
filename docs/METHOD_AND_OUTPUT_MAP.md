# Method and output map

## Computational chain

1. `data/raw/` stores the frozen Eurostat JSON-stat source responses.
2. `code/01_prepare_data.py` reconstructs the EU27 × 2010–2023 panel.
3. `code/02_analyze_progress.py` reproduces the validated progress scores, ranks, correlation grids, descriptive path quantities, country consequences, temporal results, deletion and specification checks, accounting bridge, RMC status summary and tie audit.
4. `code/03_build_results.py` retains the neutral numerical/result-package layer from the validated pipeline.
5. `code/05_build_extended_publication_evidence.py` adds the adopted publication evidence without changing the frozen panel or primary estimators: symmetric Full-grid effects, within-axis concordance, LOYO sign stability, Theil–Sen sign persistence, OLS/HC3/HAC trend diagnostics, the joint residual-block bootstrap, RMC method provenance and the all-source status audit.
6. `code/04_render_publication_figures.py` reorganizes validated analysis outputs into manuscript/Supplement table sources and figure source data, copies machine-readable supplementary evidence into the publication layer, joins values to Natural Earth geometry for map figures and renders publication artwork.

The publication renderer performs **no re-estimation** of progress scores, ranks or correlations. The extended-evidence step recomputes only the explicitly documented secondary publication diagnostics from the frozen analytical panel.

## Scientific hierarchy

The primary system-level object is the symmetric Full 3 × 2 Spearman grid. The checked-in publication sources expose the six cells, the full-grid minimum, maximum and range, symmetric conditional differences and within-axis concordance. The historical D1/D2/D3 arithmetic remains reproducible but is routed to descriptive Supplementary path evidence. The fixed difference between CMUR × territorial GHG and RMC × consumption-based GHG is labeled the **selected endpoint cell difference** and is secondary.

Country consequences retain the original rank-displacement arithmetic. Binary point-estimate differences are labeled **point-slope sign disagreement** and are accompanied by leave-one-year both-sign stability.

## Numerical reference outputs

The validated computational reference files are under `results/reference/`. The directory `results/reference/supplementary_data/` contains the adopted secondary evidence generated by `code/05_build_extended_publication_evidence.py`. RMC evidence registries are source-controlled under `data/provenance/`; the computation does not scrape live websites.

## Publication layer

- MAIN Tables 2–5: `results/reference/tables/`
- Supplement Tables S1–S9: `supplementary_tables/`
- Detailed machine-readable Supplement/Data evidence: `results/reference/supplementary_data/`
- Figure source data: `figures/source_data/`
- Vector publication artwork: `figures/reference/*.pdf`
- PNG previews: `figures/reference/*.png`
- SVG vector companions: `figures/reference/*.svg`

The exact object mapping is in `PUBLICATION_OUTPUT_MAP.csv`.

## Bootstrap execution

The joint circular moving-block residual bootstrap uses two block lengths (2 and 3), 10,000 realizations for each, fixed seeds and common whole-year residual-vector resampling across all country/series combinations. Its detailed outputs remain secondary diagnostics in Supplement/Data source evidence. MAIN Table 5 uses only the compact full-grid-range bootstrap summaries for block lengths 2 and 3. The configuration is recorded in `results/reference/supplementary_data/bootstrap_config.json`.

Paired temporal-bootstrap contrasts are computed within each draw from the corresponding two grid cells and are stored in `results/reference/supplementary_data/bootstrap_paired_contrast_summary.csv`. The descriptive population-denominator any-flag diagnostic is stored in `results/reference/supplementary_data/population_flag_rank_displacement_summary.csv`; it contains no p-values or causal interpretation.

## Determinism and tolerance

- Reconstructed baseline scientific CSVs are compared with the validated numerical reference at `1e-12`.
- Panel reconstruction is compared at `1e-6` because some source values are serialized before reconstruction.
- Extended publication evidence is regenerated and compared to the checked-in canonical outputs.
- Publication-source CSVs are compared at parsed schema/value level.
- PNG reproduction is pixel-identical; vector PDF/SVG files are checked structurally rather than by PDF byte identity because backend metadata/font object ordering can vary by platform.
- Map join keys are exact and must remain 27/27 before map rendering.


## Final full-grid robustness authority

The primary robustness object is the six-cell grid. Canonical machine-readable evidence is stored in `results/reference/supplementary_data/full_grid_fixed_sensitivities.csv`, `full_grid_deletion_runs.csv` and `bootstrap_full_grid_robustness.csv`. Every LOCO and LOYO run retains the six Spearman cells, the minimum and maximum cell identities and the full-grid range.

The additional RMC-provenance sensitivity is generated from the frozen registry in `data/provenance/rmc_country_method_registry.csv`. It excludes exactly the seven countries classified as mixed/changed and recomputes the entire six-cell grid on common n=20. The three broad provenance-group grids are retained as Supplementary diagnostics. These are provenance/composition sensitivities, not production-method effects.
